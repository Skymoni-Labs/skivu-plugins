# QQ 界面插件 1.0.0

需要 Skivu 0.2.19 及以上。在 App 插件市场安装后启用，关闭回到原版。角色、聊天记录和外观配置沿用宿主，自动动态默认关闭，资金为角色虚拟钱包。

这是数据型界面包：下载清单经 SHA-256、字节数、来源、版本与字段校验后保存；只选择 App 内编译发布的 `skivu.social-ui.v1` 渲染器，不下载执行外部脚本。更改渲染器代码需要更新 App；不能把这个清单当作任意 HTML 插件 SDK。

原创 HTML/CSS/JS 实现在 [Skivu 源码 assets/social_ui](https://github.com/skyjjgw/skivu/tree/main/assets/social_ui)。没有导入腾讯客户端代码、素材、账号数据或私有协议，不连接真实 QQ 账号或支付服务。视频/屏幕入口目前仅本机预览，Android 媒体和文件保存以宿主实际能力为准。
