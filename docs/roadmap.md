# 开放生态的当前状态

1. **界面预设**：0.2.19 起可安装 QQ/微信预设，保留协议 `1.0` 和已有 Flutter 渲染器。
2. **技能和远程 MCP**：0.2.36 起支持可主动启用的文本指导，以及用户选择工具手动调用的 Streamable HTTP MCP，使用协议 `2.0`。
3. **独立应用和聊天界面**：0.2.38 / SDK 1.0 支持插件自带 HTML/CSS/JavaScript、ES modules、Canvas/WASM 和资源，不再为第三方 ID 增加固定 renderer。可贡献独立页面、聊天动作、整个聊天界面和角色提示词，使用协议 `3.0`。
4. **开发与发布自由**：本地导入、第三方 HTTPS 目录、独立源码仓库和打包校验工具均开放。官方收录是用户可选的目录，不是开发者运行代码的前置条件。
5. **宿主能力边界**：隔离存档/文件/第三方密钥、受控网络、所选角色/聊天和模型文字生成已开放。可以连接自己的本机/电脑/自托管服务；操作系统专有能力需新增通用宿主能力和验证。不能把任意本机 shell、全部手机硬件、后台常驻或未适配上游脚本说成已经支持。

服务器私有能力、配置、账号令牌、模型密钥与签名不开放给插件。新增 API 必须维持此隔离边界。协议通过 Issue/PR 讨论，按真实实现和验收发布，不通过改目录字段冒充运行能力。
