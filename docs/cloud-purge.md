# 小云 · 规则与演练 1.0.1

[适配版源码](https://github.com/skyjjgw/skivu-cloud-purge) · [原作 YuJunZhiXue/dsh-purge](https://github.com/YuJunZhiXue/dsh-purge) · Copyright (c) 2026 小杨 · MIT（原 README 署名和附加使用说明随包保留）。本插件免费分发。

需要 **Skivu 0.2.96 或更新版本**。在“插件 → 开放插件与开发者”刷新后安装；安装保持关闭，启用前查看权限。小云工作区亦可打开该入口。插件使用小云已有的内置 Linux、Node、SQLite 和任务体系，无需独立 DSH。

支持提示词、多规则、导入/导出、草稿和应用/撤销；22 份技能正文；资产、服务、发现项、证据、凭据、会话/隧道资料、攻击链、评分、报告、知识库及角色提示词；完整资料库备份、摘要/SQLite 校验恢复和历史版本切换。Markdown 报告通过 Android 文件选择器保存；图片附件由完整资料库备份导出。

原包技能目录共 23 项，其中 `unauth-exploit.md` 已被系统防护隔离，只有不可用说明，未重新包含正文。技能可读不代表外部工具与密钥就绪。DSH 专用源码/ASAR/审批/重启补丁不适用于 Skivu；原专用并行智能体和 TCP 探测未启用。原身份替换和忽略限制提示词不会自动应用。

声明权限 `cloud.lab`、`prompt`、`files`、`assistant.tools`。小云工具读取或记录本插件资料，目标相关写入需明确演练编号；未知回执不自动重试。读取资料不等于执行外部操作。
