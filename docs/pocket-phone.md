# 角色小手机 1.1.0

一部随角色保存的独立小手机：21个应用、42个集合、31个兼容工具名，页面与业务通过开放SDK运行，按需下载。需要 Skivu 0.2.38 或更新版本。

在 App 的“插件市场 → 开放插件与开发者”刷新目录，选择“角色小手机”安装、启用并确认权限。也可从 [GitHub Release](https://github.com/skyjjgw/skivu-plugins/releases/tag/pocket-phone-v1.1.0) 下载 `.skivu.json` 本地导入。无需额外安装 Node、Linux 或新的 App 版本。

![Android 隔离测试宿主中的角色小手机，显示原创示例数据](images/pocket-phone-home.png)

## 能做什么

两页桌面、壁纸与头像、备忘录、月历与离线晨昏、浏览足迹、商品与购物车、视频记录、私密空间、书架、相册、音乐、地点总览、聊天与动态、航班、视频手记、影像动态、配送记录、播客、菜谱、书影音、闲置物品、随想与账本。完整字段均可编辑，支持原版schema1存档和图片迁入、备份导出及损坏恢复。

默认按角色隔离，可在设置中改为共用一部手机；切换保留其他空间。单次角色任务最多执行5项操作。可选聊天面板支持最多6轮模型与12项手机工具，真实回执交回下一轮，再同步最终回复到宿主聊天。私密资料默认排除，操作日志持久保存；不确定的副作用不会自动重放。

音乐通过自选网易云兼容后端搜索和前台播放，支持暂停、前后切歌和续播；生图通过自选兼容服务，预览采用后保存。两者都使用插件自己的服务配置与凭据。所有网络及模型操作走宿主代理，模型沿用宿主鉴权、内测、计费和下架保护。

## 权限与限制

需要存档、文件、插件密钥、网络、本机网络、模型生成、聊天读取和聊天写入8项权限。启用与敏感操作仍由宿主确认。音乐只对用户显式配置的loopback地址开放本机HTTP兼容，HTTP音频须同origin；生图和远程图片仅接受公共HTTPS。

手机里的交易、社交、行程等是角色模拟记录，不操作真实账号或资金。工具在插件前台聊天面板运行，未向所有原生聊天全局注册自动工具。音频单次8MiB，图片5MiB，手机存档合计6MiB，聊天日志4MiB；不保证锁屏后台播放或跨页面强事务。外部服务的账号、曲库、额度和模型遵从性需用户配置后验证。
