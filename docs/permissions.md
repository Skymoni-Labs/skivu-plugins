# 权限与宿主边界

权限以运行格式为准：旧 `prompt-pack` 草案与 `ui-preset` 为 `[]`；技能为 `prompt`；手动 MCP 为 `network`；独立 Web 插件使用[开放 SDK 的权限表](open-plugin-sdk.md)。不能把某种旧格式的限制套用到全部生态。

Web 插件可请求自己的存档/文件/第三方密钥、系统文件选择、剪贴板、所选角色/聊天、模型代理、角色提示词和网络。敏感修改与模型请求由宿主确认。自带 Web 脚本在隔离页面执行；直接本机 shell、任意原生反射、全部手机硬件及后台常驻并未因此开放。

宿主服务器的管理员能力、身份令牌、模型密钥、签名与内部配置始终不开放。网络代理不附加宿主身份；自有服务器及其解析地址不向插件开放。更新撤销原授权，停用与卸载停止运行。未来能力必须先定义接口、隔离和真实验证，再接受清单声明。

目录收录、格式校验和代码审阅不能替代运行隔离。即使扩展由官方收录，也不应自动获得额外权限或自动执行。
