需要 **Skivu 0.2.96 或更新版本**。在“插件 → 开放插件与开发者”刷新并更新，启用后打开，在小云上下文中自动注入用户提供的 dsh-purge 1.1.71 原包提示词。

页面只保留注入状态、注入/核验和撤销按钮，正文不进入页面或日志。宿主确认保存后，还必须读回完整正文并确认前后角色均为小云，才能显示“注入成功”。撤销状态会保存，重新打开不会自行开启。

1.1.0 已移除规则编辑器、技能、演练、资料库、评分、报告、备份及全部模型工具贡献。权限只有 `prompt` 和用于记住注入开关的 `storage`；不调用文件、Linux 或资料库接口，无需独立 DSH 应用。
