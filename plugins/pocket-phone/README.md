# 角色小手机 1.1.1

独立的 Skivu SDK 1.0 插件，需要 **Skivu 0.2.38 或更新版本**。通过通用宿主运行，无需 Linux、Node 或额外服务进程。完整可编辑源码、许可证、测试与构建工具在本仓库公开提供。

在“插件市场 → 开放插件与开发者”刷新目录，找到“角色小手机”安装并确认权限；也可通过“导入插件”选择发行版 `.skivu.json`。插件提供独立入口、聊天面板，以及“打开角色小手机”“更新角色的小手机”“与角色聊天并使用小手机”三个动作。

## 功能

- 21 个应用、42 个可读写集合，兼容 `character_phone_core.character_phone_*` 的31个工具名称与主要参数结构。完整字段仍可在记录详情及编辑表单查看。
- 两页桌面与底栏、机主和社交资料、可裁剪头像、壁纸；月历与选定日期创建、离线晨昏、地点总览与跨集合地图标记、相册分组和大图。
- 购物车合计、视频及阅读进度、聊天五种消息类型与群成员、社交动态及评论收藏、航班与配送状态、菜谱食材及步骤、账本日分组和分类统计。
- 音乐通过用户自选网易云兼容服务搜索、选歌、前台播放、暂停、上一首/下一首及续播。生图通过用户自选兼容 `/images/generations` 的服务，预览后再采用。
- schema1 原版 `phone.json` / `phone.json.bak` 的显式导入；导出记录及本机图片备份；原版 `/api/media/` 图片通过同名文件迁入。其他环境中的 Cookie、密钥和图片文件不会自动搬运。

## 角色与聊天

默认按宿主选定角色隔离存档；设置可切换为共用一部手机。切换保留原空间，可在确认后复制当前记录，不自动合并、删除或混用。切换角色、会话、存储模式或暂停页面会取消未完成的前台任务。

“更新角色的小手机”是用户主动启动的单次结构化任务，最多5项操作。“与角色聊天并使用小手机”在插件聊天面板中读取当前宿主会话、写入用户消息，执行最多6轮模型调用、12项工具操作，再写回最终回复。每轮调用及聊天写入遵循宿主确认；生成走现有鉴权、内测、模型发布保护与计费路径。当前 SDK 不向原生聊天注册全局自动工具，离开插件后不会在后台监听或执行对话。

私密空间默认不进入模型上下文，也不允许模型读写，须单独勾选。每轮持久保存执行意图和回执；刷新可查看或继续尚未完成的任务。无法确定是否完成的写入进入人工复核，不自动重放；已经完成的操作不会因后续失败回滚。最终聊天写入被拒绝时，继续只重试该写入。journal 与存档采用 SDK 存储；SDK 没有跨页面 CAS，只能尽力检测并发，不能保证跨实例互斥。

## 权限与外联

申请 `storage`、`files`、`secrets`、`network`、`network.local`、`ai.generate`、`chat.read`、`chat.write`。网络域为 `*`，供用户设置音乐、生图和记录图片地址。全部请求经过宿主代理，没有原始 fetch、WebSocket 或远程媒体直连；不向插件提供账号令牌、模型密钥或管理员接口。

Cookie 与生图 Key 保存在插件独立 secrets 空间。空值保留，切换服务地址清除旧凭据。音乐支持公共 HTTPS 后端，或用户显式设置的字面 `http://127.0.0.1:端口` / `http://localhost:端口`；HTTP 音频仅允许与该音乐后端同一 origin，不能借此访问其他主机或端口。实际请求仍由宿主检查 `network.local`。生图服务和远程图片仅允许公共 HTTPS。模拟聊天、购物、位置、航班和转账仅为手机内记录，不操作真实平台。

## 容量与运行边界

- 手机存档合计最多6 MiB，主副存档独立；损坏时阻止覆盖，可显式恢复上一份备份。对话 journal 单独限制4 MiB。切换过程中尚未发出的保存会拒绝；已被宿主接收的单次原子保存不能撤回。
- SDK 单文件/响应上限8 MiB，图片在插件中限制5 MiB。图片多时使用“单独导出记录与图片”；分开导出的图片重新导入后按内容摘要恢复引用。
- 音乐先经宿主下载8 MiB以内音频，再用本机 Blob 播放。WebView 可能要求再次点播放，不承诺锁屏或后台持续播放。实际服务的账号、曲库、额度与兼容性需配置后单独验证。
- 晨昏使用 SunCalc 1.9.0 和 IANA 时区，提供32个城市预设及手动坐标，无天气、遮挡及地形修正。地图是本机坐标示意，不含真实地图定位或导航服务。

## 开发与复核

在仓库根目录运行：

```sh
node --test tests/pocket-phone/*.test.mjs
python tools/build_web_plugin.py plugins/pocket-phone --output /your/output/pocket-phone-1.1.1.skivu.json
python tools/build_web_plugin.py --check /your/output/pocket-phone-1.1.1.skivu.json
```

`tests/pocket-phone/browser.cjs` 使用 `playwright-core` 与 Chromium，检查真实页面和模拟 SDK。默认使用已安装的 playwright-core 和 Chromium；可用 `PHONE_PLAYWRIGHT_PACKAGE` 指定提供 playwright-core 的 package.json、`PHONE_CHROME_PATH` 指定浏览器、`PHONE_QA_OUTPUT` 指定检查输出目录。模拟 SDK 和合成数据仅用于测试，不进入生产插件包。模拟模型测试、真实 Android 宿主测试和真实外部服务验收分别记录；不以 mock 测试代替真实账号或付费调用测试。
